₹15,000 ke andar phone lena matlab sahi trade-off chunna. Ye rahi simple checklist.

## 1. Processor aur RAM
Naya 5G chipset dekho, aur agar bahut saare apps khule rakhte ho toh **kam se kam 6 GB RAM** lo. Gaming karte ho toh 8 GB better hai.

## 2. Storage
**128 GB ya zyada** lo. Memory card slot hai ya nahi, check karo.

## 3. Display
90 Hz ya 120 Hz screen zyada smooth lagti hai. AMOLED mein colours aur dhoop mein brightness LCD se better hoti hai.

## 4. Battery aur charging
5,000 mAh normal hai. Charging speed **aur** box mein charger aata hai ya nahi, dono dekho.

## 5. Software updates
Brand kitne saal ke Android aur security updates deta hai, ye zaroor check karo.

## 6. Kharidne se pehle
- Same model ka price Amazon, Flipkart aur Croma pe compare karo. Bank offers badalte rehte hain.
- Heating aur battery complaints ke liye recent reviews padho.
- Return aur replacement policy check karo.
